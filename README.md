# 个人知识库 macOS Beta

本仓库仅发布 Apple Silicon macOS Beta 安装包、签名更新清单和版本说明，不包含应用源码或用户数据。

[下载最新 Beta 3003](https://github.com/echoechofu/research-graph-beta/releases/tag/b3003)

r5 及更旧版本需手动安装一次带更新器的版本。安装到 Applications 后打开；设置页可检查更新。原生窗口确认下载及重启，安装前等待后台任务、备份数据库，文献和学习笔记仍在原 Application Support 目录。

应用使用 ad-hoc 签名，未 notarize。首次打开按系统提示手动允许是正常安装步骤；不需要关闭 Gatekeeper 或删除隔离属性。

最低声明 macOS 14；实际验证 macOS 15.6.1。公开应用内更新链 3001 → 3002 已验证，3003 增加安装期间旧应用重启保护。Beta 尚未完成 macOS 14 实机及所有网络中断场景验收。

旧版本安装包保留在 Releases，已发布文件不会覆盖。
